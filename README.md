# ฟอร์มบันทึกประวัติการซื้อของลูกค้าใน Google Sheets

สคริปต์ Google Apps Script ที่ผมใช้กับ Google Sheets ตอนช่วยงานแอดมินของบริษัทครอบครัว ช่วงปิดเทอมใหญ่ก่อนขึ้น ม.4 (ปี 2567) เป็นโค้ดชิ้นแรกที่ผมนั่งแก้เองจนใช้งานได้ และเป็นจุดที่ทำให้ผมเริ่มชอบการเขียนโปรแกรม

ผู้จัดทำ: พิสิษฐ์ เกจณะเวชช์

## ที่มา

ตอนนั้นผมต้องไล่ชื่อลูกค้าจากไฟล์ Excel ทีละรายการ จึงหาวิธีใน YouTube แล้วเจอคลิปของครูอภิวัฒน์ "สอนสร้างสื่อ" เรื่อง [การสร้างฟอร์มบันทึก อัพเดต ลบข้อมูลใน Google Sheet ด้วย App Script](https://www.youtube.com/watch?v=iJNhaNu0B_4) ซึ่งแจก[โค้ดต้นฉบับ](https://gist.github.com/neno-tech/c13733d3c77d1abf28500f8a866a2dc8)ไว้ ผมคัดลอกโค้ดนั้นมาแล้วแก้เองจนใช้กับข้อมูลของบริษัทได้

งานนี้ผมไม่ได้ใช้ AI และไม่ได้เขียนขึ้นใหม่จากศูนย์

## ส่วนไหนมาจากคลิป ส่วนไหนผมแก้

| | โค้ดต้นฉบับจากคลิป | ฉบับที่ผมใช้ (`Code.gs`) |
|---|---|---|
| ความยาว | 75 บรรทัด | 183 บรรทัด |
| จำนวนช่องในฟอร์ม | 6 ช่อง | 29 ช่อง ใส่สินค้าได้ 10 รายการ |
| ฟังก์ชัน | `Submit` `Clear` `Search` `Update` `Delete` | 5 ตัวเดิม และเพิ่ม `BringUp` `SaveData` `ClearForm` |

- โครงของ 5 ฟังก์ชันแรกมาจากคลิป ผมเปลี่ยนชื่อแท็บ เปลี่ยนตำแหน่งช่อง และขยายจาก 6 ช่องเป็น 29 ช่องให้ตรงกับข้อมูลลูกค้าของบริษัท
- `BringUp()` ผมเพิ่มเองโดยดูแบบจาก `Search()` เพื่อให้พิมพ์รหัสลูกค้าแล้วดึงข้อมูลลูกค้าจากหน้าทะเบียนมาใส่ฟอร์ม
- `SaveData()` ได้จากการอัดมาโครของ Google Sheets ใช้ทำสำเนาหน้าตารางกับหน้ากราฟเก็บไว้ตอนสิ้นเดือน
- `ClearForm()` ผมเพิ่มเพื่อล้างข้อมูลในตารางก่อนเริ่มเดือนใหม่

## สคริปต์ทำอะไร

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `Submit()` | อ่านค่าจากฟอร์ม แล้วต่อท้ายตารางประวัติการซื้อ |
| `Clear()` | ล้างช่องในฟอร์ม |
| `Search()` | หาแถวจากรหัสลูกค้า แล้วเติมข้อมูลลงฟอร์ม |
| `Update()` | เขียนค่าจากฟอร์มทับแถวของลูกค้ารายนั้น |
| `Delete()` | ถามยืนยัน แล้วลบแถวของลูกค้ารายนั้น |
| `BringUp()` | พิมพ์รหัสลูกค้าแล้วดึงข้อมูลลูกค้าจากหน้าทะเบียนมาใส่ฟอร์ม |
| `SaveData()` | ทำสำเนาหน้าตารางและหน้ากราฟเก็บไว้ |
| `ClearForm()` | ล้างข้อมูลในตาราง |

## สิ่งที่ไม่อยู่ใน repo นี้

ตัวชีตและข้อมูลในชีตไม่ได้เผยแพร่ เพราะมีข้อมูลลูกค้าของบริษัท ใน repo นี้มีเฉพาะโค้ด

## เกี่ยวกับ repo

โค้ดเขียนเมื่อปี 2567 แต่ตอนนั้นผมยังไม่ได้ใช้ Git จึงเพิ่งอัปโหลดเมื่อเดือนตุลาคม 2569 โค้ดในไฟล์ `Code.gs` เป็นฉบับเดิมตามที่ใช้งานจริง ส่วนคำอธิบายหน้านี้ผมให้ AI ช่วยเรียบเรียงจากที่ผมเล่า
